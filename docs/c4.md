## Nível 3: componentes

```mermaid
flowchart LR
  api["API Express"] --> slices["Application: Create, Get, List, Update, Delete"]
  slices --> domain["Domain: validações e invariantes"]
  slices --> ports["Porta Repository injetada"]
  mongo["Infrastructure: MongoRepository"] -.->|"Implementa"| ports
  sql["Infrastructure: SqlRepository"] -.->|"Implementa"| ports
  sql --> tx["Transação: Certificate e Outbox"]
  publisher["Application: PublishEvents"] -->|"Lê pendentes"| sql
  publisher -->|"Envia base64"| queue["Azure Queue"]
  queue --> trigger["Function: campusEvents"]
  trigger --> process["Application: ProcessEvent"]
  process --> table["Infrastructure: TableLedger"]
```

As portas são contratos de objetos injetados em JavaScript. Eventos e certificados têm repositórios, processos e bancos próprios. O BFF não importa código desses serviços. O gateway é a única entrada pública dos containers na configuração Azure.
